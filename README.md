# Lanterne de Courge : Les Clés du Manoir

**Gare aux courants d'air spectraux**

Joue en ligne sur : [https://games.hylst.fr/lanternecourge/](https://games.hylst.fr/lanternecourge/)

## Description
Escape game mystérieux au manoir de Valombre : collecte des allumettes pour nourrir ta lanterne, découvre des inscriptions secrètes, crochete des serrures en laiton et consulte le grimoire.

## Controles
| Contrôle | Action |
|---|---|
| Clic / Tap | Explorer le Grand Salon, manipuler les serrures |
| Inventaire | Combiner et utiliser les clés et bougies |

## Developpement
```bash
# Installer les dependances
npm install

# Lancer le serveur local
npm run dev

# Compiler pour la production (build single-file)
npm run build
```
