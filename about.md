# A propos de Lanterne de Courge : Les Clés du Manoir

**Lanterne de Courge : Les Clés du Manoir** est un escape game / enquête spectrale developpe par **Geoffroy Streit** (alias **Hylst**).

## Le jeu
Escape game mystérieux au manoir de Valombre : collecte des allumettes pour nourrir ta lanterne, découvre des inscriptions secrètes, crochete des serrures en laiton et consulte le grimoire.

## Le createur
- Developpeur d'applications, ancien graphiste et compositeur
- Adepte de retrocomputing et de demoscene
- Createur de la plateforme de jeux 100% front-end Hylst.Games

## Stack technique
- React 19 + TypeScript + Tailwind CSS 4
- Vite 7 + vite-plugin-singlefile
- 100% statique, sans serveur ni collecte de donnees
